# Marketing Website

The public front door, separate from the logged-in app — without it, self-service signup (see [[Multi-Tenancy]]) has no discoverable entry point beyond direct personal outreach.

## Scope (build alongside Phase 1)
A simple one-page site:
- What it does (plain-language pitch for a Ghanaian shop owner)
- Pricing (GHS 50–100/month, single plan — see [[Business-Model]])
- "Start free trial" → signup flow
- Referral code capture if arriving via a shared link (see growth loop in [[Business-Model]])

## Not yet decided
- Product name (see [[Open-Risks]])
- Domain name
- Visual design — presumably follows [[Design-Language]] for consistency, but a marketing page has different goals (persuasion) than the in-app product (efficiency), so some deviation may be warranted — revisit when building
